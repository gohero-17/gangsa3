# 칼퇴를 부르는 AI 직무 스쿨

4주·8개 차시의 AI 실무 학습 로드맵입니다. `index.html` 하나로 동작하며 설치나 빌드가 필요하지 않습니다.

- 학습 진도와 차시별 메모를 현재 브라우저의 localStorage에 저장합니다.
- 8개 차시 완료 시 축하 모달을 표시합니다.
- 진도 초기화는 확인 후 메모와 완료 상태를 함께 지웁니다.
- 저장이 제한된 브라우저에서는 저장 불가 안내를 표시합니다.
- 서버·계정·기기 간 동기화 기능은 없습니다.

## 실행과 배포

`index.html`을 브라우저에서 열거나 정적 웹 서버로 실행하세요. Vercel에서는 프레임워크 Other, 별도 빌드 명령 없이 저장소 루트를 배포합니다. Google Fonts 외부 폰트 로딩에 실패하면 시스템 폰트로 표시됩니다.

첨부된 개인 이력서와 강의계획서(PDF·HWP)는 Git 및 배포 대상에서 제외합니다.
