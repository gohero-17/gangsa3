07 / FAQ

담당자님이
자주 묻는 질문.

교육비와 세부 운영 조건은
문의 시 개별 안내해 드립니다.

기관 내부 PC의 외부 접속이 제한되어도 가능한가요?

사전에 외부망 접속 가능 여부와 사용할 수 있는 AI 도구를 확인합니다. 실제 접속 가능한 도구와 실습 방식을 협의해 기관 환경에 맞게 구성합니다.

생성형 AI를 처음 사용하는 직원도 따라갈 수 있나요?

자료 정리 → 초안 → 팩트체크 순서로 단계별 실습을 진행합니다. 사전 상담에서 수강자의 경험을 확인하고 난이도를 조정합니다.

보안 규정과 민감 정보 유출 예방도 다루나요?

비식별화와 데이터 입력 시 주의사항을 안내합니다. 실습은 공개·가상자료로 진행하며 실제 개인정보와 비공개 정보는 입력하지 않습니다. 기관 자체 보안 지침을 우선 확인합니다.

반일 특강으로 어떤 결과물을 만들 수 있나요?

템플릿을 활용해 준비한 주제의 보고서 초안과 검증본을 완성하는 것을 목표로 합니다. 주제의 복잡도와 수강자의 경험에 따라 실습 범위를 사전에 조율합니다.
